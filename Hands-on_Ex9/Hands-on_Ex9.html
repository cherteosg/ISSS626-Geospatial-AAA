Modelling Geographical Accessibility

Published

October 27, 2026

Modified

October 27, 2026

Introduction

The geography of accessibility measures how easily people can overcome distance and spatial barriers to reach important destinations like jobs, schools, healthcare, and shops. It moves beyond raw physical distance to evaluate how time, transport networks, cost, and individual constraints shape real-world

Questions that can be answered by accessibility models are:

  • Which part of the geographical areas are deprived from getting access to a social service, facility or job opportunity?

  • Which part of the geographical areas will be affected by a public policy or business decision such as merging JCs, secondary and primary schools.

In this hands-on exercise, we will model geographical accessibility by using R’s geospatial analysis packages.

Learning Outcomes

  • Import GIS polygon data into R and save them as simple feature data frame by using appropriate functions of sf package of R;

  • Import aspatial data into R and save them as simple feature data frame by using appropriate functions of sf package of R;

  • Compute accessibility measure by using Hansen’s potential model and Spatial Accessibility Measure (SAM); and

  • Visualise the accessibility measures by using tmap and ggplot2 packages.

Data

Four data sets will be used in this hands-on exercise, they are:

  • MP14_SUBZONE_NO_SEA_PL: URA Master Plan 2014 subzone boundary GIS data. This data set is downloaded from data.gov.sg.

  • hexagons: A 250m radius hexagons GIS data. This data set was created by using st_make_grid() of sf package. It is in ESRI shapefile format.

  • ELDERCARE: GIS data showing location of eldercare service. This data is downloaded from data.gov.sg. There are two versions. One in ESRI shapefile format. The other one in Google kml file format. For the purpose of this hands-on exercise, ESRI shapefile format is provided.

  • OD_Matrix: a distance matrix in csv format. There are six fields in the data file. They are:

    • origin_id: the unique id values of the origin (i.e. fid of hexagon data set.),
    • destination_id: the unique id values of the destination (i.e. fid of ELDERCARE data set.),
    • entry_cost: the perpendicular distance between the origins and the nearest road),
    • network_cost: the actual network distance from the origin and destination,
    • exit_cost: the perpendicular distance between the destination and the nearest road), and
    • total_cost: the summation of entry_cost, network_cost and exit_cost.

All the values of the cost related fields are in metres.

Reminder: Except MP14_SUBZONE_NO_SEA_PL data set, the other three data sets are specially prepared by Prof. Kam for teaching and research purpose and can only be used for this hands-on exercise. Formal approval from Prof. Kam is required for use in other courses or purpose.

Data Cleaning & Update

Exclude redundant fields in the data tables of both eldercare and hexagons and create new fields (demand and capacity) using mutate() of dplyr package.

Code 
eldercare <- eldercare %>% 
  select(fid, ADDRESSPOS) %>% mutate(capacity = 100)

hexagons <- hexagons %>% 
  select(fid) %>% mutate(demand = 100)

Note that for the purpose of this hands-on exercise, a constant value of 100 is used. In practice, actual demand of the hexagon and capacity of the eldercare centers should be used.

Aspatial Data Handling and Wrangling

Import Aspatial Data

Import OD_Matrix.csv using read_cvs() of readr package. The imported object is a tibble data.frame called ODMatrix.

Code 
ODMatrix <- read_csv("data/aspatial/OD_Matrix.csv", 
                     skip = 0)

Tidy Distance Matrix

The imported OD Matrix is organised in a long format (‘thin’) where each row represents a trip from origin to destination.

However, modelling packages in R require a wide format (‘fat’) where rows are origins and columns are destinations.

spread() of tidyr package is used to transform the OD Matrix from a thin format into a fat format.

Code 
distmat <- ODMatrix %>%
  select(origin_id, destination_id, total_cost) %>%
  arrange(origin_id, destination_id) %>%
  pivot_wider(names_from = destination_id,
              values_from = total_cost) %>%
  select(-origin_id) %>%
  as.matrix()

Currently, the distance is measured in meters because the SVY21 projected coordinate system is used. convert the unit of measurement from meters to kilometers.

Code 
distmat_km <- as.matrix(distmat/1000)

Modelling and Visualising Accessibility using Hansen Method

Hansen’s Accessibility

Compute Hansen’s accessibility by using ac() of SpatialAcc package. data.frame() is used to save the output in a data frame called acc_Hansen.

Code 
acc_Hansen <- data.frame(ac(hexagons$demand,
                            eldercare$capacity,
                            distmat_km,
                            d0 = 50,
                            power = 2,
                            family = "Hansen"))

Rename the default field name to ‘accHansen’.

Code 
colnames(acc_Hansen) <- "accHansen"

Convert the data table into tibble format.

Code 
acc_Hansen <- as_tibble(acc_Hansen)

Use bind_cols() of dplyr to join the acc_Hansen tibble data frame with the hexagons simple feature data frame.

Code 
hexagon_Hansen <- bind_cols(hexagons, acc_Hansen)

Notice that hexagon_Hansen is a simple feature data frame and not a typical tibble data frame.

The above can be combined into a single code chunk if preferred.

Visualising Hansen’s Accessibility

Extracting Map Extend

Extract the extend of hexagons simple feature data frame by using st_bbox() of sf package.

Code 
mapex <- st_bbox(hexagons)

Use the mapping functions in the tmap package to create a high-quality cartographic map of accessibility to eldercare centres in Singapore.

Code 
tm_shape(hexagon_Hansen, 
         bbox = mapex) + 
  tm_polygons(fill = "accHansen", 
              fill.scale = tm_scale_intervals( 
                style = "quantile", 
                n = 10, 
                values = "brewer.blues")) + 
tm_shape(eldercare) + 
  tm_dots(size = 0.3, 
          fill = "red", col = 
            "black") + 
  tm_title("Accessibility to eldercare: Hansen method") +
  tm_layout(frame = TRUE) + 
  tm_compass(type="8star", size = 2) + 
  tm_scalebar() + 
  tm_grid(alpha = 0.2)
